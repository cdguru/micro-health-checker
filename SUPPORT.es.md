- Utilizá GitHub Discussions para preguntas de instalación y conversaciones de diseño.
- Utilizá GitHub Issues para bugs reproducibles y funcionalidades aceptadas.
- Utilizá los security advisories privados de GitHub para vulnerabilidades.

El soporte comunitario se ofrece según disponibilidad. Cuando solicites ayuda, incluí la versión de la aplicación, el backend de almacenamiento, una configuración sin datos sensibles y los logs JSON relevantes.
